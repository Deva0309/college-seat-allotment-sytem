# College Seat Allotment System

A Full Stack Development project built using HTML, CSS, Python Flask and SQLite.

## Project Description

The College Seat Allotment System helps students find and receive college/course seats based on their entrance rank, category, course preferences and available seats.

The system checks the student's preferences in order and allocates an available seat when the student satisfies the rank criteria.

## Technologies Used

- HTML5
- CSS3
- Python
- Flask
- SQLite
- Jinja2
- Git
- GitHub

## Features

- Student registration
- Rank-based seat allotment
- Category-based eligibility
- Course preferences
- Seat availability
- Automatic seat reduction after allotment
- Allotment result page
- Admin dashboard
- Student allotment records
- Seat reset functionality
- Responsive design
- SQLite database
